# Aprovação DMAE 2026 — Oficial Administrativo (Fundep)

Cursinho completo para o concurso do **DMAE Uberlândia 2026**, cargo **Oficial Administrativo**
(prova em 01/11/2026, banca Fundep). Feito para entrar nas 10 vagas.

> ⚠️ **O cargo é OFICIAL ADMINISTRATIVO** — não "Auxiliar Administrativo" (esse nome só existe
> como tema dentro de Conhecimentos Específicos). Confira o código do cargo na inscrição.

## O que tem aqui

| Arquivo | O que é |
|---|---|
| `index.html` | **Site de estudo** interativo: edital verticalizado, plano de 7 semanas, simulado que corrige sozinho (40 questões) e 80 flashcards. Abre em qualquer navegador. |
| `CLAUDE.md` | Instruções do **tutor no Claude Code** (questões ilimitadas + correção personalizada). |
| `base_conhecimento_dmae_2026.md` | Base de conhecimento que o tutor lê (todo o conteúdo do concurso). |
| `leis/` | Coloque aqui os PDFs/textos das leis e o Edital Consolidado (o tutor cita artigo e prazo sem inventar). |

## Como estudar (2 formas)

**1. Site (leitura + prática):** abra o `index.html` (duplo clique) ou acesse a versão publicada.
Faça o simulado, clique em **Corrigir prova**, revise os flashcards e marque o cronograma
(o progresso fica salvo no seu navegador).

**2. Tutor infinito (Claude Code):** no terminal, dentro desta pasta, rode `claude`. Peça
"monte a sessão de hoje", "simulado de 10 questões da Lei 14.133", "corrija: 11-A, 12-B…",
"faltam 5 dias: revisão final".

## Publicar (deploy)

Este é um site estático (um `index.html`), então publicar é simples:

- **Vercel (conta gustav.8854@gmail.com):** vercel.com → *Add New → Project* → importe o repositório

- **GitHub Pages (alternativa que já liga sozinha):** Settings → Pages → Source: `main` / `/root`.
